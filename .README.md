# SafeNet Nigeria — Phase 1
## Nigeria Conflict Intelligence System

### Quick Start (3 steps)

```bash
# 1. Clone and enter project
cd safenet-phase1

# 2. Set up environment
cp .env.example .env
# Edit .env with your ACLED credentials (see below)

# 3. Run the full pipeline
python run_pipeline.py
```

Open `dashboard/index.html` in your browser. Done.

---

### Getting ACLED Access

1. Go to **https://acleddata.com/register/**
2. Fill the form — select "Academic / Research" or "NGO / Civil Society"
   (SafeNet qualifies as civic security research)
3. Your API key arrives by email — usually within 1 business day
4. Add to your `.env` file:
   ```
   ACLED_API_KEY=paste_your_key_here
   ACLED_EMAIL=the_email_you_registered_with
   ```
5. Run `python run_pipeline.py` — it automatically switches to live data

Until you have credentials, the pipeline runs on **synthetic data** that
mirrors the exact ACLED schema — so all your code works identically.

---

### Environment Variables

| Variable | Required | Description |
|---|---|---|
| `ACLED_API_KEY` | For live data | From acleddata.com |
| `ACLED_EMAIL` | For live data | Your registered email |
| `DATABASE_URL` | Production only | PostgreSQL URL |
| `ENVIRONMENT` | No | `development` or `production` |
| `TERMII_API_KEY` | Phase 3+ | SMS alert gateway |
| `SECRET_KEY` | Production | Random secret string |
| `LOG_LEVEL` | No | `DEBUG`, `INFO`, `WARNING` |

```

├── .gitignore            ← Protects your secrets from Git
├── config.py             ← Central env var loader
├── run_pipeline.py       ← Master run script
│
├── pipeline/
│   ├── acled_ingestor.py ← Day 1: Extract conflict data
│   ├── database.py       ← Day 2: Transform + Load (ETL)
│   └── generate_dashboard.py ← Day 3: HTML dashboard
│
├── data/
│   └── safenet.db        ← SQLite intelligence store (auto-created)
│
└── dashboard/
    └── index.html        ← Your live intelligence dashboard
```

### Switching to Production (PostgreSQL)

```bash
# Install PostgreSQL driver
pip install psycopg2-binary

# Set in .env
DATABASE_URL=postgresql://user:password@host:5432/safenet_db
ENVIRONMENT=production
```

The pipeline detects this automatically — no code changes.
